# Scooter Media Assets Folder

Please drop your logo and property photograph files into this `assets/` folder.

Recommended naming:
- `logo.svg` or `logo.png` - Primary logo
- `logo-white.svg` or `logo-white.png` - Header/Footer white logo
- `hero-bg.jpg` - Hero background image
- `work-skyline.jpg` - Skyline Residences image
- `work-private.jpg` - Private Collection image
- `work-district.jpg` - The New District image
- `work-desert.jpg` - Desert Modern image
